JMS API: 提供Messaging中间件标准, 适用任何(Event)事件驱动的系统
1. JMS provides the facility to create, send and read messages.
2. JMS provides a common interface for standard message protocols and message services
3. JMS helps in building the communication between two or more applications

JMS: 异步可靠
1. 减低系统的耦合性，进行messaging的APP不需要存在依赖关系
2. 消息的发布者并不需要消息的接收者存在时才发送信息，消息的接受者会自动fetch消息
3. JMS保证消息只会被deliver一次

JMS Impl:
- Apache ActiveMQ: Client, Broker
- Apache ActiveMQ: Artemis, Artemis-Server
- Apache RocketMQ
